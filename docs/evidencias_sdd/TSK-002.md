## Separação entre modelo e execução local

A Tool `somar_inteiros` é demonstrativa, tipada e sem efeitos colaterais. O modelo apenas retorna uma solicitação estruturada e os argumentos. O código Python valida esses argumentos, executa efetivamente a função local e envia o resultado ao modelo para a resposta final. O Structured Output ocorre em outra chamada, com JSON Schema estrito, e é validado novamente por `SaidaEstruturadaSmoke.model_validate`.
